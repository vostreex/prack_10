# 5.4 Реализация модуля «Мотивация и вдохновение» с использованием Retrofit и ZenQuotes API

## 5.4.1 Архитектура модуля

Модуль «Мотивация и вдохновение» реализован в соответствии с принципами Clean Architecture и использует библиотеку Retrofit для взаимодействия с внешним REST API (ZenQuotes). Архитектура модуля включает следующие слои:

- **Data Layer**: содержит DTO (Data Transfer Objects), мапперы для преобразования данных, remote data source для работы с API и local data source для работы с локальной базой данных SQLite.
- **Domain Layer**: содержит репозитории (интерфейсы), use cases для бизнес-логики и доменные модели.
- **Presentation Layer**: содержит MobX stores для управления состоянием и UI компоненты (экраны, виджеты).

## 5.4.2 Настройка Retrofit API клиента

Для работы с ZenQuotes API был создан декларативный API клиент с использованием аннотаций Retrofit:

**Файл**: `lib/data/datasources/remote/api/zenquotes_api_client.dart`

```dart
@RestApi(baseUrl: 'https://zenquotes.io/api')
abstract class ZenQuotesApiClient {
  factory ZenQuotesApiClient(Dio dio, {String baseUrl}) = _ZenQuotesApiClient;
  
  @GET('/random')
  Future<List<ZenQuoteDto>> getRandomQuote();
  
  @GET('/today')
  Future<List<ZenQuoteDto>> getQuoteOfTheDay();
  
  @GET('/quotes')
  Future<List<ZenQuoteDto>> getQuotes();
  
  @GET('/quotes/{keyword}')
  Future<List<ZenQuoteDto>> searchQuotes(@Path('keyword') String keyword);
  
  @GET('/quotes/{author}')
  Future<List<ZenQuoteDto>> getQuotesByAuthor(@Path('author') String author);
  
  @GET('/quotes/{category}')
  Future<List<ZenQuoteDto>> getQuotesByCategory(@Path('category') String category);
}
```

**Особенности реализации**:
- Использование аннотации `@RestApi` для указания базового URL API
- Декларативное описание методов с помощью аннотаций `@GET`
- Использование `@Path` для динамических параметров в URL
- Автоматическая генерация кода реализации через `retrofit_generator`
- Отсутствие ручных Dio-запросов — вся логика HTTP-взаимодействия генерируется автоматически

## 5.4.3 Реализация DTO и мапперов

Для корректной сериализации JSON-ответов от API были созданы DTO (Data Transfer Objects) с использованием `json_annotation`:

**Файл**: `lib/data/dtos/zenquotes/zen_quote_dto.dart`

```dart
@JsonSerializable()
class ZenQuoteDto {
  @JsonKey(name: 'q')
  final String quote;
  
  @JsonKey(name: 'a')
  final String author;
  
  @JsonKey(name: 'i')
  final String? imageUrl;
  
  @JsonKey(name: 'c')
  final String? characterCount;
  
  @JsonKey(name: 'h')
  final String? html;
  
  factory ZenQuoteDto.fromJson(Map<String, dynamic> json) => 
      _$ZenQuoteDtoFromJson(json);
  
  Map<String, dynamic> toJson() => _$ZenQuoteDtoToJson(this);
}
```

**Особенности**:
- Использование аннотации `@JsonSerializable()` для автоматической генерации сериализации
- Маппинг полей JSON API на поля Dart-класса через `@JsonKey`
- Автоматическая генерация методов `fromJson` и `toJson` через `json_serializable`

Для преобразования DTO в доменные модели был создан маппер:

**Файл**: `lib/data/mappers/zenquotes_mapper.dart`

```dart
class ZenQuotesMapper {
  static MotivationItem zenQuoteDtoToMotivationItem(ZenQuoteDto dto) {
    final text = '${dto.quote} – ${dto.author}';
    return MotivationItem(
      id: '${dto.author}_${dto.quote.hashCode}',
      text: text,
      category: 'Без категории',
      type: 'quote',
    );
  }
  
  static List<MotivationItem> zenQuoteDtoListToMotivationItems(
    List<ZenQuoteDto> dtos
  ) {
    return dtos.map((dto) => zenQuoteDtoToMotivationItem(dto)).toList();
  }
}
```

## 5.4.4 Реализация Remote Data Source

Remote Data Source является оберткой над Retrofit API клиентом и предоставляет методы для работы с ZenQuotes API:

**Файл**: `lib/data/datasources/remote/motivation_remote_datasource.dart`

**Реализованные методы**:
1. `getRandomQuote()` — получение случайной цитаты через `GET /api/random`
2. `getQuoteOfTheDay()` — получение цитаты дня через `GET /api/today`
3. `getQuotes()` — получение списка из 20 цитат через `GET /api/quotes`
4. `searchQuotes(String query)` — поиск цитат по ключевому слову через `GET /api/quotes/{keyword}`
5. `getQuotesByAuthor(String author)` — получение цитат конкретного автора через `GET /api/quotes/{author}`
6. `getQuotesByCategory(String category)` — получение цитат по категории через `GET /api/quotes/{category}`

**Особенности**:
- Обработка ошибок с преобразованием в понятные сообщения
- Проверка на пустые ответы от API
- Извлечение первого элемента из массива для методов, возвращающих одиночные цитаты

## 5.4.5 Интеграция с Repository и Use Cases

Repository (`MotivationRepositoryImpl`) объединяет работу с remote и local data sources:

**Файл**: `lib/data/repositories/motivation_repository_impl.dart`

**Реализованные методы**:
- `getRandomQuote()` — получение случайной цитаты из API
- `getQuoteOfTheDay()` — получение цитаты дня из API
- `searchQuotes(String query)` — поиск цитат через API
- `getQuotesByAuthor(String author)` — получение цитат автора через API
- `getQuotesByCategory(String category)` — получение цитат по категории через API
- `getCategories()` — возвращает предопределенный список категорий ZenQuotes: life, love, success, happiness, inspiration, motivation, wisdom, friendship, philosophy, faith, truth

**Особенности**:
- Использование маппера для преобразования DTO в доменные модели
- Обработка ошибок с fallback на пустые результаты
- Комбинирование категорий из API и локальной БД

## 5.4.6 Реализация UI и State Management

UI реализован с использованием MobX для управления состоянием:

**Файл**: `lib/ui/features/motivations/state/motivation_store.dart`

**Особенности реализации**:
- Раздельные observable-переменные для состояния загрузки каждого типа данных:
  - `isQuoteOfTheDayLoading` — загрузка цитаты дня
  - `isRandomLoading` — загрузка случайной цитаты
  - `isCategoryLoading` — загрузка цитат категории
  - `isSearchLoading` — загрузка результатов поиска
  - `isAuthorLoading` — загрузка цитат автора
  - `isFactLoading` — загрузка фактов
- Отдельные списки и текущие значения для каждого типа цитат:
  - `searchQuotesList` и `currentSearchQuote` — для результатов поиска
  - `authorQuotesList` и `currentAuthorQuote` — для цитат автора
  - `categoryQuotesList` и `currentCategoryQuote` — для цитат категории
- Методы для обновления только соответствующих данных:
  - `nextSearchQuote()` — обновляет только результат поиска
  - `nextAuthorQuote()` — обновляет только цитаты автора
  - `nextCategoryQuote()` — обновляет только цитаты категории
  - `loadRandomQuote()` — загружает новую случайную цитату
  - `nextFact()` — обновляет только факт

**Файл**: `lib/ui/features/motivations/screens/motivation_screen.dart`

**Структура экрана**:
1. Поле поиска с кнопкой "Найти" — поиск выполняется только по нажатию кнопки
2. Карточка результатов поиска — отображается сразу под полем поиска при наличии результатов
3. Поле фильтра по автору с кнопкой "Найти" — фильтрация выполняется только по нажатию кнопки
4. Карточка цитат автора — отображается сразу под полем автора при наличии результатов
5. Dropdown выбора категории
6. Карточка "Цитата дня" — без кнопки обновления (только поделиться)
7. Карточка "Цитата из категории" — с кнопкой обновления
8. Карточка "Случайная цитата" — с кнопкой обновления
9. Карточка "Факт о продуктивности" — с кнопкой обновления

**Особенности UI**:
- Каждая карточка имеет независимую кнопку обновления, которая обновляет только соответствующие данные
- Индикаторы загрузки отображаются индивидуально для каждого типа данных
- Карточки поиска и автора появляются динамически только при наличии активных фильтров
- Использование `Observer` из `flutter_mobx` для реактивного обновления UI

## 5.4.7 Настройка Dependency Injection

Все компоненты зарегистрированы в GetIt для dependency injection:

**Файл**: `lib/main.dart`

```dart
// Регистрация Dio клиента
GetIt.I.registerLazySingleton<Dio>(() => Dio());

// Регистрация ZenQuotes API клиента
GetIt.I.registerLazySingleton<ZenQuotesApiClient>(
  () => ZenQuotesApiClient(GetIt.I<Dio>()),
);

// Регистрация Remote Data Source
GetIt.I.registerLazySingleton<MotivationRemoteDataSource>(
  () => MotivationRemoteDataSource(GetIt.I<ZenQuotesApiClient>()),
);

// Регистрация Repository
final motivationRepository = MotivationRepositoryImpl(
  GetIt.I<MotivationLocalDataSource>(),
  GetIt.I<MotivationRemoteDataSource>(),
);
```

## 5.4.8 Генерация кода

Для работы Retrofit и JSON сериализации используется автоматическая генерация кода через `build_runner`:

**Команда генерации**:
```bash
flutter pub run build_runner build --delete-conflicting-outputs
```

**Генерируемые файлы**:
- `zenquotes_api_client.g.dart` — реализация Retrofit API клиента
- `zen_quote_dto.g.dart` — методы сериализации/десериализации JSON
- `motivation_store.g.dart` — MobX код для реактивности

**Особенности**:
- Все изменения в API клиенте или DTO требуют перегенерации кода
- Генерация происходит автоматически при сборке проекта
- Конфликтующие файлы автоматически перезаписываются

## 5.4.9 Обработка ошибок

Реализована многоуровневая обработка ошибок:

1. **Уровень API клиента**: Dio автоматически обрабатывает сетевые ошибки
2. **Уровень Remote Data Source**: Преобразование исключений в понятные сообщения
3. **Уровень Repository**: Обработка ошибок с fallback на пустые результаты
4. **Уровень Store**: Установка сообщений об ошибках в observable-переменные
5. **Уровень UI**: Отображение сообщений "Нет результатов" или "Не удалось загрузить"

Модуль поддерживает следующие функции:
